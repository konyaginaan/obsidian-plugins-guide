Настройка двух плагинов Obsidian

Smart Connections сам находит заметки, похожие по смыслу. Templater сам расставляет структуру — теги и место для источника — в каждой новой заметке.

Smart Connections Templater Если что-то не работает

Перед началом. Оба плагина ставятся одинаково — через встроенный каталог Obsidian. Работает только на компьютере (Mac/Windows/Linux), не в мобильном приложении. Понадобится интернет один раз — на установку.

Про язык интерфейса. Английские названия кнопок не меняются ни при каком языке Obsidian — в скобках русский вариант, но формулировка может отличаться версии от версии. Не нашли надпись — ищите по значку (не переводится): шестерёнка — настройки, пазл — плагины. Настройки самих плагинов почти всегда на английском независимо от языка Obsidian — это нормально.

Часть 1Smart Connections — умный поиск похожих заметок

Показывает заметки, близкие по смыслу к той, что вы сейчас читаете — даже если между ними нет прямой ссылки [[...]].

Важно перед установкой

Smart Connections требователен к версии Obsidian — на старой версии он может не установиться или не заработать без объяснения причины. Проверьте версию заранее: Settings («Настройки») → в левом меню раздел General («Общие») → прокрутите вниз, там будет строка с номером текущей версии и кнопка Check for updates («Проверить обновления»). Если кнопка есть и предлагает обновление — нажмите и обновитесь, потом возвращайтесь к установке.

Установка

  1. Откройте Settings («Настройки») — значок шестерёнки в самом низу левой боковой панели.

  2. В меню настроек слева найдите и нажмите Community plugins («Сторонние плагины»).

  3. Если видите кнопку Turn on community plugins («Включить сторонние плагины») — нажмите её. Obsidian покажет предупреждение про безопасность стороннего кода — это нормально, нажмите ещё раз, чтобы подтвердить.

  4. Нажмите кнопку Browse («Обзор») — откроется каталог плагинов.

  5. В строке поиска наверху введите Smart Connections — название плагина везде на английском, по-русски его не переводят и не ищут.

  6. Нажмите на карточку плагина, затем на кнопку Install («Установить»).

  7. После установки на месте кнопки появится переключатель — включите его (Enable / «Включить»).

  8. Закройте настройки.

Проверка

Справа (или слева, если панели поменяны местами) появится новая иконка на боковой панели. Нажмите на неё — откроется панель Smart Connections. В первый раз плагину нужно время, чтобы «прочитать» все заметки — может занять от пары минут до получаса, в зависимости от размера хранилища. Пока идёт эта работа, панель может быть пустой или показывать индикатор загрузки — это ожидаемо, просто подождите.

После этого при открытии любой заметки в панели будет появляться список похожих заметок с процентом совпадения — чем выше число, тем ближе смысл.

Часть 2Templater — готовая структура для новой заметки

При создании новой заметки автоматически подставляется заготовка — например, поле для тегов и поле для источника — вместо пустого листа.

Установка

  1. Так же как и раньше: Settings («Настройки») → Community plugins («Сторонние плагины») → Browse («Обзор»).

  2. В поиске введите Templater (название на английском, не переводится), откройте карточку, нажмите Install («Установить»), затем включите переключатель (Enable / «Включить»).

Шаг 1 — папка для заготовок

  1. В левой панели с файлами нажмите правой кнопкой мыши по названию хранилища (самый верх списка) → New folder («Новая папка»).

  2. Назовите её, например, Шаблоны.

Шаг 2 — сама заготовка

  1. Нажмите правой кнопкой по папке Шаблоны → New note («Новая заметка»). Назовите заметку, например, Шаблон заметки.

  2. Внутри новой заметки найдите раздел Properties («Свойства») в самом верху (если не видно — наведите курсор чуть выше текста, появится строка с кнопкой «плюс»).

  3. Нажмите + Add property («Добавить свойство»), введите имя tags и выберите тип List («Список») — оставьте поле пустым, оно будет заполняться в каждой новой заметке отдельно.

  4. Нажмите + Add property ещё раз, введите имя Источник, тип — Text («Текст»), тоже оставьте пустым.

Заготовка будет выглядеть так — это то, что появится наверху каждой новой заметки:

Свойства
tags+ добавить
Источник—

Шаг 3 — включить автоматическую подстановку

Дальше — настройки самого плагина Templater. Они будут на английском независимо от языка Obsidian (это не ошибка, так у всех сторонних плагинов) — рядом даю перевод названий полей просто для понимания.

  1. Settings («Настройки») → Community plugins («Сторонние плагины») → найдите в списке включённых плагинов Templater → нажмите на значок шестерёнки рядом с его названием.

  2. Найдите поле Template folder location (переводится как «папка с шаблонами») — укажите папку Шаблоны, которую создали в шаге 1.

  3. Включите переключатель Trigger Templater on new file creation (буквально «запускать Templater при создании нового файла») — из-за него заготовка будет подставляться сама, без лишних действий.

  4. В поле выбора шаблона по умолчанию (обычно называется Default new file template) укажите заметку Шаблон заметки.

Проверка

Создайте новую заметку (значок с плюсом наверху левой панели или сочетание Cmd/Ctrl + N). Если сверху сразу видны пустые поля tags и Источник — всё настроено верно.

Если что-то пошло не так

Ищите ситуацию, которая похожа на вашу, и делайте по шагам — не нужно разбираться, почему так вышло.

Не нахожу плагин, когда ищу его в каталоге

Впишите название заново, буква в букву, латиницей: Smart Connections или Templater. Русской раскладкой или переводом искать не получится — названия плагинов всегда на английском.

Если название введено верно, но список всё равно пустой — проверьте, что компьютер подключён к интернету: каталог плагинов загружается из сети каждый раз, когда вы его открываете.

Не вижу кнопку «Turn on community plugins» / «Включить сторонние плагины»

Скорее всего, они уже были включены раньше — тогда вместо этой кнопки сразу видна кнопка Browse («Обзор»). Можно смело переходить к следующему шагу.

Установила плагин, но после перезапуска Obsidian переключатель сам выключился

Обычно это значит, что плагин не смог запуститься — чаще всего из-за устаревшей версии Obsidian. Проверьте версию: Settings («Настройки») → General («Общие») → внизу страницы номер версии и кнопка Check for updates («Проверить обновления»). Обновитесь, если предлагается, и включите плагин заново.

Templater не подставляет заготовку в новой заметке

Загляните в настройки плагина (шестерёнка рядом с его названием в списке плагинов) и проверьте по порядку:

1. Включён ли переключатель Trigger Templater on new file creation.

2. Указана ли заметка-шаблон в поле выбора шаблона по умолчанию.

3. Правильно ли указана папка с шаблоном в поле Template folder location — если папку потом переименовали или переместили, здесь нужно поправить вручную.

Панель Smart Connections пустая или ничего не показывает

Если хранилище большое (сотни заметок и больше), первичная обработка может идти долго — оставьте Obsidian открытым и просто подождите, ничего нажимать не нужно.

Если прошло больше часа и панель всё ещё пустая — откройте настройки плагина и проверьте, не стоит ли обработка на паузе. Если и это не помогло — вернитесь к самому первому шагу и проверьте версию Obsidian, устаревшая версия — самая частая причина.

Интерфейс Obsidian не на английском и не на русском (или незнакомый язык)

Все инструкции выше всё равно сработают — ориентируйтесь на значки: шестерёнка всегда открывает настройки, значок пазла — плагины, значок с плюсом — создание новой заметки или папки. Расположение пунктов в меню от языка не зависит.

Если хочется на время переключить весь Obsidian на английский, чтобы легче было сверяться с этой инструкцией: Settings → General → поле Language → выбрать English. Обратно можно переключить в любой момент тем же способом.
